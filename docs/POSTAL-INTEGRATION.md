# Postal integration retired

The October 2026 results on this page documented local preview and the former
Postal/SMTP implementation. Postal and SMTP are no longer supported. Those test
results are historical and do not verify Resend transport or webhook behavior.

Use [Resend email setup](RESEND.md) for current setup and [Resend verification](RESEND-VERIFICATION.md)
for current checks. No Resend account, API key, sender DNS, or live delivery has
been configured or verified in this workspace.
